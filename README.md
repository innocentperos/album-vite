# Album Vite (Album Quick)
An online photo and album sharing platform using
vue 3, vite and tailwind css.
'Vue 3', 'Tailwind css','Vite'

## Features
1. Facial Recognition in images
2. Album sharing
3. Chats
4. Image and album filtering by individuals (Similar to Google Photos)

## Tech stack
1. Backend, uses django (python)
2. Uses S3 Bucket and PostGres for storage and database engine.
3. Vue 3, Tailwind CSS and vite for frontend.
